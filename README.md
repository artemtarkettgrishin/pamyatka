# Памятка продавца — версия 10

Каталог хранится в обычных Google-листах. Главное меню — отдельно; у каждого узла отдельное дочернее меню; у каждого уровня с товарами — своя таблица; у каждого журнала — свой лист. JSON-снимки версии 8/9 не используются как рабочее хранилище после миграции.

**Установка и обновление:** `START_GUIDE_FOR_BEGINNERS.md`. Обязательно подключить Advanced Google Sheets API (`Sheets`, v4), запустить `installWorkbook`, обновить развёртывание и сайт.

## Состав

- `dist/index.html` — готовое приложение.
- `public/google-apps-script.js` — полный серверный скрипт для Apps Script.
- `public/appsscript.json` — пример манифеста с сервисом и правами.
- `server/Backend.template.gs` — авторизация, чтение версии, CAS и идемпотентные запросы.
- `server/Workbook.gs` — раздельные листы, структурное чтение, точечные пакетные записи, триггеры.
- `server/Legacy.gs` — одноразовое чтение предыдущего хранилища и незавершённых правок v9.
- `shared/catalog.js` — контракт данных и объединение независимых изменений.
- `src/utils/writeQueue.ts` — очередь отправки и устойчивые черновики из версии 8.
- `AUDIT_REPORT.md` — устройство, проверки и ограничения.

## Разработка

Node.js 22+ (проверено на Node.js 24).

```sh
npm ci
npm test
npm run build
```

Генерация серверного файла автоматически выполняется перед сборкой и тестами. Правьте файлы `server/` и `shared/`, затем пересобирайте; не изменяйте только сгенерированный файл.

```sh
npx playwright install chromium --only-shell
npm run test:browser
```

Браузерные проверки используют настоящее приложение с исполнением серверного Apps Script в локальной модели API. Внешний аккаунт Google не изменяют.

`npm run test:visual` сравнивает текущий `dist/index.html` с `../baseline-v8/dist/index.html`. Для самостоятельного повторения распакуйте ранее выданную версию 8 в соседнюю папку `baseline-v8`. Результаты и скриншоты выполненного сравнения находятся в `test-results/`.

Оформление каталога сохранено. На мобильных товарная таблица находится выше декоров. В административном редакторе добавлено поле ID, а кнопке входа присвоена доступная подпись без визуального изменения.
