# Памятка — синхронизация v11 для существующих таблиц К10

Начните с `UPDATE_V10_TO_V11.md`. Это обновление уже установленной v10 без переноса данных и без изменения дизайна.

- `Backend-v11.gs` — полный серверный код для замены прежнего кода Apps Script.
- `dist/index.html` — готовая страница для статической публикации.
- `src`, `shared`, `server`, `scripts` — исходники. При обновлении сохраните ваш действующий `src/config.ts` с адресом подключения.
- `rollback` — сервер и готовая страница прежней v10; собственная резервная копия установленной версии предпочтительнее.
- `AUDIT_REPORT.md`, `test-results` — изменения, проверки и ограничения.

Не запускайте setup/installWorkbook для обновления уже работающей Google Таблицы. Не импортируйте демонстрационный initialData в действующий каталог.

Команды разработчика: `npm ci`, `npm test`, `npm run build`, `node tests/performance.mjs`.
Браузерные проверки: `npx playwright install chromium`, затем `npm run test:browser` и `npm run test:visual` в среде, где разрешён запуск браузера. При необходимости можно задать PLAYWRIGHT_CHROMIUM_EXECUTABLE.

Формат Google Таблицы и gasVersion оставлены 10 для совместимости. Новые возможности транспорта обозначены syncProtocol:11. Название старой версии во встроенном окне кода оставлено вместе с неизменным интерфейсом; сам встроенный скрипт обновлён.
